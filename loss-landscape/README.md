# Loss Landscape: Why Skip Connections Matter

**Author:** Youngjin Kim (ykim9554@usc.edu)
**Course:** USC EE508 — Spring 2026

An interactive 3D visualization of the core finding from Li et al., *"Visualizing the Loss Landscape of Neural Nets"* (NeurIPS 2018, [arXiv:1712.09913](https://arxiv.org/abs/1712.09913)):

> Without skip connections, deep networks have chaotic loss landscapes full of local minima. With skip connections, the landscape becomes approximately convex and gradient descent reliably reaches the global minimum.

## What This Teaches

1. **Drop 50 balls** on a ResNet-56 surface **with** skip connections. Nearly all converge to the global minimum (green).
2. **Toggle skip connections off**. The same ensemble scatters: many get trapped in local minima (red) or diverge (gray).
3. **Increase depth to 110** without skip connections. The landscape becomes dramatically worse.

The live counter provides a *quantitative* version of the paper's qualitative finding — exact convergence fractions, not just pictures.

## How to Run

Open `loss-landscape-skip-connections.html` in any modern browser. No server required — all data is embedded.

## Controls

| Control | What it does |
|---------|-------------|
| **Depth** (20 / 56 / 110) | Switches the network depth; deeper noshort = more chaotic |
| **Skip Connections** (On / Off) | Toggles residual connections; the key comparison |
| **Optimizer** (SGD / Momentum / Adam) | Changes the gradient descent variant for ball physics |
| **Learning Rate** | Log-scale slider from 1e-4 to 1e-1 |
| **Momentum beta** | Visible when Momentum is selected; default 0.9 |
| **Balls** (1–200) | Number of random starting points |
| **Drop Balls** | Randomize and release the ensemble |
| **3D Surface / 2D Contour** | Switch between views |

## Technical Details

- **Plotly.js** for 3D surface rendering with Viridis colormap
- **Bilinear interpolation** on precomputed gradient grids for smooth ball trajectories
- **Three optimizers** with correct implementations (SGD, Momentum with configurable beta, Adam with bias correction)
- **Convergence detection**: |z - z_min| < 0.05 (converged), ||grad|| < 0.01 for 30 frames (stuck), |position| > 1.05 (diverged)
- **log(Loss + 1)** z-axis transform matching the reference paper's convention
- Dark theme, responsive layout, touch support for mobile

## Surface Data

Currently uses **synthetic placeholder surfaces** generated by `tools/synth_surfaces.py`. These use Gaussian bumps to create realistic-looking terrain that qualitatively matches the paper's findings.

To generate surfaces from real pre-trained models, use `tools/h5_to_json.py` with `.h5` files from [tomgoldstein/loss-landscape](https://github.com/tomgoldstein/loss-landscape).
