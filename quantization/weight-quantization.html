Symmetric vs Asymmetric

Symmetric sets zero-point = 0, maps [−max, max] uniformly. Asymmetric uses a separate zero-point offset, better for one-sided distributions (e.g., ReLU outputs ≥ 0).

📊

Per-tensor vs Per-channel

Per-tensor uses one scale for all weights — fast but coarse. Per-channel assigns one scale per output neuron, capturing different weight magnitudes per filter with only minor overhead.

⚠️

Outliers hurt quality

A single large outlier forces a wide scale, wasting most of the INT8 range on values near zero. Methods like SmoothQuant and GPTQ redistribute outliers before quantization.
