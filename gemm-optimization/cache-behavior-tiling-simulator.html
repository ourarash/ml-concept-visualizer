Cache Behavior & Tiling Simulator

Interactive visualization of cache hits, misses, and evictions during GEMM matrix multiplication. See LRU replacement, cache thrashing, and the cache cliff phenomenon in action.

What You'll Learn

Cache Behavior During GEMM: Matrix multiplication accesses three matrices (A, B, C). Without tiling, data is accessed once and evicted before reuse. With tiling, small blocks fit in L1 cache and are reused multiple times, dramatically improving hit rates.

LRU Replacement: When a cache set is full (all 8 ways occupied), the Least Recently Used line is evicted to make room for new data. You'll see LRU ages (0=newest, 7=oldest) and watch the oldest lines get replaced.

Cache Thrashing: When the working set exceeds cache capacity, data is constantly evicted before it can be reused. You'll see frequent yellow evictions and red misses, with hit rates below 30%.

Cache Cliff: As tile size increases, performance initially improves (better reuse), but once tiles exceed L1 capacity (~32KB), performance collapses. The "cliff" is the sharp transition from high hit rates (85%+) to thrashing (20%).
