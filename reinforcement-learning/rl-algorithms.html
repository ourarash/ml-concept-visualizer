Q-Learning

Online

Learns a Q-function Q(s,a) — the expected discounted reward for taking action a in state s. The agent uses an ε-greedy policy: explore randomly with probability ε, otherwise act greedily on Q.

Q(s,a) ← Q(s,a) + α[r + γ·maxa'Q(s',a') − Q(s,a)]

Cells are colored by max Q-value. The best action arrow appears once Q-values diverge from zero.

  • α = 0.10 — learning rate
  • γ = 0.95 — discount factor
  • ε — starts at 1.0, decays each episode → 0.05
  • Update: after every single step (TD(0))
  • Paradigm: Off-policy (learns greedy policy while following ε-greedy)

REINFORCE

Online

Directly parameterizes and optimizes the policy π(a|s;θ). Runs a full episode, computes discounted returns Gt, subtracts a per-episode baseline b, then nudges θ to increase the probability of actions with above-baseline returns.

θ ← θ + α · (Gt − b) · ∇θ log π(at|st; θ)
Gt = Σ γk·rt+k  |  b = meantGt  |  π(a|s) = softmax(θs,a)

Arrow thickness = action probability. Trajectory shown in yellow; return sign colours the path.

  • α = 0.05 — policy learning rate
  • γ = 0.95 — discount
  • Update: once per full episode (Monte Carlo)
  • Paradigm: On-policy Monte Carlo; baseline reduces variance
  • Weakness: still needs many episodes to reduce variance

Actor-Critic

Online

Combines value-based and policy-based methods. The Actor (policy) decides actions; the Critic (V-function) evaluates them via TD error δ, replacing Gt with a lower-variance bootstrap estimate.

δ = r + γ·V(s') − V(s)  ← TD error
θ ← θ + αA·δ·∇θ log π(a|s)  ← actor
w ← w + αC·δ·∇w V(s)  ← critic

Cell colour = critic V(s). Arrows = actor π(a|s). Flash = TD error sign.

  • αA = 0.05 — actor LR
  • αC = 0.10 — critic LR
  • Update: every step (TD(0))
  • vs REINFORCE: lower variance via critic bootstrap
  • vs Q-Learning: explicit stochastic policy (actor)
