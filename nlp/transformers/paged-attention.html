PagedAttention

How vLLM eliminates KV cache memory waste in LLM serving

What is PagedAttention?

During LLM inference, every generated token appends new Key and Value vectors to the KV cache — a GPU memory buffer that grows with each decoding step. Traditional systems pre-reserve a large contiguous chunk per request (sized for the worst-case output length), wasting 60–80% of GPU memory on slots that never get used.

PagedAttention (Kwon et al., vLLM 2023) borrows the OS concept of virtual memory paging: it divides the KV cache into fixed-size physical pages that are allocated on demand and mapped via per-request block tables. Pages for the same request don't need to be contiguous — so memory is only allocated when a token is actually generated, eliminating waste and enabling 2–4× more concurrent requests on the same GPU.
