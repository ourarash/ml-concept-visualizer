1. Shifted next-token labels

The model receives token x_i and learns to predict label y_i = x_{i+1}. The final token has no next-token label, so it is ignored.

2. Causal attention mask

Position i can only use tokens at positions <= i. If it could see future tokens, the training task would leak the answer.

4. Logits and softmax

Softmax uses p_i = exp(logit_i / T) / sum_j exp(logit_j / T). Lower temperature sharpens the distribution; higher temperature flattens it.

6. Gradient microscope

For logits z, the gradient is dL/dz_i = p_i - y_i. Gradient descent subtracts this gradient, so the target logit increases and overconfident wrong logits decrease.

7. Teacher forcing vs inference

Training uses gold previous tokens. Inference uses the model's previous generations, so an early mistake changes future context. This mismatch is often called exposure bias.

Training / teacher forcing

The prefix always follows the gold sequence.

Inference / free running

The prefix includes the model's generated tokens.

Mini quiz

Why are labels shifted by one position?

Because causal language modeling trains position i to predict the next token, x_{i+1}, from the prefix ending at x_i.

Why does the causal mask matter during training?

It prevents the model from attending to future tokens that contain the answer it is supposed to predict.

What happens to loss if the target probability is very small?

The loss grows because cross-entropy uses -log(p_target). Small target probabilities create large penalties.

Why might we ignore prompt tokens during instruction tuning?

Ignoring prompt labels focuses the loss on assistant responses instead of teaching the model to reproduce user or system prompts.
